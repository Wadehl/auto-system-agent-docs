一次运行的执行顺序

sequenceDiagram
  autonumber
  actor U as 用户
  participant E as Editor
  participant W as Web
  participant G as Go API
  participant D as Daemon
  participant R as Claude Runtime
  U->>E: 打开开发模式
  E->>W: 提供页面标识与快照
  W->>G: 同步 Workspace / Revision
  U->>W: 发送消息并选择 Session
  W->>G: 创建 Run
  G->>D: 启动 Run + Session ID
  D->>R: Claude Agent SDK query / resume
  R-->>D: 文本增量、工具请求、终态
  D-->>G: 运行事件
  G-->>W: SSE 推送
  R->>D: deliver_patch
  D->>W: 请求 Editor 审批
  W->>E: 转发 Patch
  U->>E: 审阅并保存
  E-->>W: 保存后的完整快照
  W->>G: 同步新 Revision
  G-->>D: 已确认的工具结果
  D-->>R: 继续当前 Runtime

Daemon 重启不会恢复原 Runtime 进程或其内存事件缓冲。Go API 持久化的 Session 绑定和 Claude Session 文件可供新 Run 尝试续接；这不等于恢复旧 Run。
