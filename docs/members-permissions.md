当前版本服务于本机开发者，不包含团队成员、角色或多租户权限系统。

## 当前权限边界

开发模式控制 Agent 工作台的入口，不等同于用户身份认证或服务端授权。当前没有成员邀请、Workspace 角色、跨用户数据隔离或组织配额。

自动化平台 JWT 服务于 Editor 的业务访问。本地 Agent API 尚未接入完整服务端身份校验，也不把 JWT 当作多租户授权机制。

## 共享服务前需要补齐

- 服务端身份认证与 Workspace 级授权。
- 用户、组织和 Workspace 的归属关系及数据隔离。
- Runtime 凭据隔离、工具授权、资源配额与审计。
- 多副本需要的共享持久化、幂等与分布式调度。

:::warning
不要把当前本地服务直接作为多人生产服务部署。
:::
